HOW TO PLAY

1. Swipe a colored block up, down, left or right. It slides until something stops it.

2. A block leaves the board only through the gate with the same color on the edge.

3. Blocks can block each other - think about the order!

4. Clear all blocks before the timer ends. Stuck? Use a HINT.
